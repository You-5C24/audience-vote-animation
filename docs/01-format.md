# 01 · 格式：观众投票的每日连载

外网有一类号（例：IG @30daystofix，7 天 8 条涨到 27 万粉）：一个卡通角色，N 天后有件大事，每天一集，每集结尾让观众二选一，票多的下一集改掉，改了就不变回去。观众投完票，第二天会回来看结果。

只学格式，不学人家的角色、设定、配色和台词。

## 每集都守的规矩

1. 每天一集，40–50 秒，竖屏 9:16，「Day N of 30」
2. 每集结尾二选一投票；票多的下一集改掉，改了不会变回去（fixed stays fixed，程序保证，见 02）
3. 顶部面板：DAY N/30 + 进度条（例：DATE-READY），每改一样涨 3–5%；最后的结果看总进度
4. 只拿生活习惯开涮（卫生、房间、作息、穿着、社交），不拿长相、身材、种族、疾病开玩笑；「去健身」可以，「嘲笑胖」不行
5. 不用真人、真品牌、别人的角色

## 每集结构

| 时间 | 内容 |
| --- | --- |
| 0–3 秒 | 直接给结果：「Day 2. You picked haircut.」+ 改之前的样子（钩子，也让投票的人马上看到自己的票生效） |
| 3–25 秒 | 改的过程，一个笑点：这件事对主角有多难；在某个词上切到改之后的样子（FIX_AT），进度条往上涨 |
| 25–35 秒 | 冒出新问题，或配角（短信）推一下剧情 |
| 35–45 秒 | 新的二选一 + 「Comment one word」；结尾「N days left」 |

第 1 集不一样：介绍主角、大事、他现在有多惨（3–4 个笑点）、规则，最后第一个投票。见 `examples/30-days-to-the-date/ep01/script.json`。

## 投票怎么出

- 两个选项要有分歧：一个容易一个难、一个有用一个好笑；评论区吵起来才有互动
- 两条剧情都提前想好，哪个赢做哪个
- 偶尔改成「点赞最多的评论决定」，收观众的奇葩点子；不安全、不合适的跳过，换下一条
- 落选的那个可以留到后面再投，别让它消失

## 三幕（30 天）

- **第 1 幕 Day 1–7：先活得像个人**（卫生和房间，最好笑）。Day 7 放一个钩子（例：相亲对象的半张头像 + 一个和没修好的东西有关的身份）
- **第 2 幕 Day 8–20：变成能见人的人**（作息、穿着、技能）。中点（Day 15）让对方主动来一条消息，第一次用「点赞最多的评论」替主角回；Day 20 投票定约会地点
- **第 3 幕 Day 21–29：练习和翻车**（社交）。Day 28 一次大翻车，Day 29 悬念（「Can we move it to tonight?」）
- **Day 30：大事当天**。结局按总进度分三档；最后再投一次：要不要第二季

## 配角

越少越好做：一个只在手机短信里出现的家人（催、补刀），一个到最后才露脸的对象，一两个道具角色（会站立的袜子、外卖盒塔、窗外的鸽子）。
