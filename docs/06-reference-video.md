# 参考视频如何进入本集

每集优先拆用户提供的 @30daystofix 参考片。记录「时间范围｜看到和听到什么｜起到什么作用｜本集怎么拍」。抽帧核对构图和镜头顺序，连续预览核对动作和切点，实际复听核对卡点和混音。标记未核验的部分。把采用的做法写入出片卡，并在短预览中验证。

## 出片卡与短预览检查

开拍时把以下内容填进当集出片卡。首集可跳过上一票。

- **上一集**：实发链接或已确认版本、片尾投票原词、结票时的有效票、采用的分支及原因、向观众承诺的动作。评论总量单独记。信息待核实时，标出哪些镜头依赖结果。
- **首帧与首句**：主角手上正在做什么、眼前遇到什么、旁白要补哪条因果。静音看前 5 秒，核对观众能否看懂本集动作和阻碍，再带声检查首句能否接住画面。
- **逐拍分镜**：时间范围、角色动作、可见结果、下一镜接什么。连续两拍只在重复解释时，尝试合并，或让一个道具或决定在后续镜头产生新后果。
- **动作与声音**：记下动作、接触帧或台词锚点、音效和留白。预览最容易做错的接触或转场，先静音检查站位和动作，再带声检查卡点与人声。参考片音效尚未复听时，标为待核验。
- **投票与接续**：两侧各用可识别的道具和动作说明选项，写出 A、B 胜出后下一集各自的第一镜。片尾交代怎么投，并留出读卡时间。交审前核对画面、旁白、正文和置顶评论的投票词。

## 内容饱满

- 开场让上一票改变角色当下的动作，背景按理解所需补入。
- 每一拍提供一个动作、发现、反应或后果。配角带具体任务入场。道具可以先制造阻碍，再交付笑点，后续继续产生影响。
- 画面演动作和反差，旁白补动机和因果，屏幕文字补时间、价格或条件。留白给观众读卡和看反应。剪掉重复解释和没有新进展的空拍。
- 片尾让 A/B 各演一拍，提前核对下一集有新动作可兑现。

## 音效卡点

- 在分镜记录「动作事件｜画面帧或台词锚点｜声音｜留白」。碰撞、落地、卡住、界面变化跟画面帧，字幕强调可跟词时间。
- 反转前可收音乐或留半拍，等反应出来再接旁白。复听音效是否抢人声、被音乐盖住，或提前泄露笑点。台词或剪辑改动后复查对应时间点。
- 短预览带上切镜前后各一拍。波形可以检查声音起点，听感以实际复听为准。

## 音效库与新增素材

1. 根据参考片和本集画面列出要发声的动作，先按动作标签查系列的音效来源清单。可复用的提示音沿用原素材，裁切、增益和时间点在当集混音里调。
2. 缺少合适素材时，按具体动作搜 Pixabay，例如 `cardboard box flap`、`packing tape peel`、`box set down`。简单界面音也可以用现有合成工具。先把候选放进带旁白的短预览，确认卡点、留白和可懂度再入库。
3. 原文件保留在系列素材目录。来源清单记录素材名、作者、原链接、动作标签和经核实的首次使用集数或镜头。当集混音记录采用的文件和事件锚点。技能仓库只保存指南、链接和代码。Pixabay 原音频的单独分发受其 [内容许可](https://pixabay.com/service/license-summary/) 限制。

## 转场

- 写清「上一镜留下什么｜下一镜接什么」。可用人物视线、手中道具、进行中的动作或问答接过去。照片切实景可对齐同一扇窗或家具，消息界面可由角色掏手机引出。
- 切前让观众读到结果或反应，切后尽快交代主体和动作。必要时让下场声音提前进入，或让上场声音跨过切点。
- 静音看动作和空间是否连得上，再带声核对声音接缝、停顿和旁白顺序。保留本系列的原创角色和视觉设计。
